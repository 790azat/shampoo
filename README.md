# SHAMPOO

Pixel-art browser platformer set in Yerevan. Play as Azat or Arsen, run through six districts, collect BOOM, Adrenaline Rush, VIP, TEREA and Head & Shoulders, fill the DJ meter and blast stray dogs with vinyl and notes.

Single self-contained `index.html`: open it in a browser, no build step.

**Controls:** ← → / A D move, ↑ / W / Space jump, ↓ / S crouch, X / J shoot in DJ mode, Esc pause, M mute. On phones, on-screen buttons (landscape).
